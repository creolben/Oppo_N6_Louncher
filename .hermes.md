constraints live in `PRODUCT.md` -- read it before changing behavior or visuals.

## Build / verify
- `flutter pub get`
- `flutter analyze` -- must be clean before declaring work done
- `flutter test`
- `flutter build apk` for device builds (see `flutter-android-delivery` skill)

## Must preserve (from PRODUCT.md)
- Galaxy ticker, node morphing, camera pan/zoom/inertia, fold transitions,
  gestures, hit testing, launch supernova, reduce-motion support.
- HOME role, package queries, keyguard delegation, hinge sensor,
  app-return bridge, wallpaper preview.
- No root, SystemUI hooks, private ColorOS APIs, or unlicensed OEM assets.
