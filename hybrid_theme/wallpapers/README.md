# Wallpaper source

`chronofold-cosmic-static.svg` is the owned static companion for the in-app `CosmicLiveWallpaperService`. The legacy filename is retained for package compatibility; the artwork now carries ChronoFold's **Luminous Horizon** visual system.

- It is authored at **1080 × 2400**.
- Export a device-matched WebP or PNG before adding it to a ColorOS theme package.
- Use the live wallpaper for drifting light, twinkle, meteor, parallax, and core motion; use this SVG when a device or ROM accepts only static wallpaper assets.
- No ColorOS wallpaper, font, icon, or proprietary artwork is embedded.
- Do not call the static asset an animated lock screen. The secure lock screen remains owned by ColorOS.
